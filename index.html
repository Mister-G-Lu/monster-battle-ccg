Monster Battle CCG — Offline Android Build

This project is an Android-only offline build of the English Card Battle game. The Shadow Road campaign, all battles, and the card game itself run inside the Android app — there is no web/browser version.

Install English_offline.apk from the repository root on an Android device (allow unknown sources), then launch the app. It works fully offline, no account or Internet connection required.

Source and build instructions live in the GitHub repository.
